# Node Backend

Un backend de node (server) básico, sin frameworks, con el módulo http. Se implementa un servidor web que responde a peticiones HTTP. 

- El servidor se crea con la función createServer() del módulo http de Node.js. 
- El servidor escucha en un puerto específico y responde a las solicitudes entrantes. 
- Se pueden manejar diferentes rutas y métodos HTTP para proporcionar diferentes funcionalidades.

La información teórica se encuentra en 9.Node\info\info.node.md

- createServer()
- callback (app) con req y res
- puerto y variables de entorno
- listen(port, callback)
- rutas y métodos HTTP
- respuestas JSON (index1.html)
- ficheros estáticos (index2.html)

No se aplica ninguna separación de caps
